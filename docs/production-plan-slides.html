From proof-of-concept to a multi-hospital platform

100s of hospitals
high event & call throughput
HIPAA-grade · self-healing
POC today
Full loop proven on one node, one hospital, synthetic data: ECG classification → graph + vector KB → criticality-gated call → grounded Q&A. Single-instance stores.
Production target
Multi-tenant, observable, compliant platform — continuous streaming telemetry, horizontal scale across sites & beds, HA and self-healing throughout.
01Multi-tenancy & isolation
per-hospital tenancy, KB namespacing, PHI segregation, tenant routing
02Streaming telemetry
edge MQTT → partitioned stream bus, live waveform/vitals MQTT→WebRTC, store-and-forward, sliding-window inference
03Event bus & processing
Kafka partitioned by hospital+patient, DLQ, idempotency, backpressure
04Model serving
ECG on Triton/GPU (batch, autoscale), LLM on vLLM cluster, model registry
05Voice at scale
LiveKit cluster, SIP capacity, K8s worker autoscaling (job-per-room)
06Data stores HA
Neo4j cluster, Qdrant sharding, time-series DB for waveforms, object store
07Observability
OpenTelemetry tracing, Prometheus/Grafana, SLOs, PHI-safe logs, drift + stream-lag
08Reliability
retries, circuit-breakers, graceful degradation, DR/backup, chaos + load tests
09Security & compliance
HIPAA/SOC2, BAAs, KMS encryption, RBAC/SSO, de-id validation, pen-test
10Clinical / regulatory⚠ SaMD
guardrail eval, red-team, clinical review, FDA-510(k) path if decision-support
11Integration
FHIR/HL7 EHR at scale, per-site device gateways, edge deploy for on-prem PHI
12MLOps & DevEx
retraining, eval, drift detection, A/B; K8s + Terraform, CI/CD, multi-region
